fix(windows): hide command windows for auto-slash-command execSync spawns

Yeachan-Heo/oh-my-claudecode PR #3484 (fix(windows): avoid Git console flashes in hooks and HUD) 이 src/hooks/auto-slash-command/live-data.ts 안의 git-specific execFileSync 콜 두 개는 fix 했지만 같은 파일의 general command runner (executeCommand, !begin-script 블록 러너) 두 개는 그대로 남아 !cmd 치환·유저 스크립트 실행마다 Windows에서 cmd.exe console flash가 재발생. 두 spot에 windowsHide: true 만 추가하고 기존 회귀 테스트 두 케이스에 assertion 강화.

배경 — #3484 sweep이 놓친 spot

#3484는 checkIfModified, checkIfBranch 두 git 특화 함수를 execSync → execFileSync 로 바꾸며 windowsHide: true 를 붙였음. 하지만 같은 파일 안의 다음 두 general command runner는 스윕 대상에서 빠졌음:

  • executeCommand(command) — 매 !cmd live-data 치환마다 호출
  • !begin-script 블록 러너 — 유저가 마크다운 안에 넣은 shell 블록 실행

두 콜 다 execSync. Windows에서 shell 경유 스폰이라 cmd.exe 창이 매번 잠깐 뜸.

변경

두 execSync 옵션 객체에 windowsHide: true 만 추가. #3484 및 이전 스윕들이 다 unconditional로 세팅한 패턴 그대로 — Node는 non-Windows 에서 이 옵션을 무시하니 platform check 불필요.

회귀 테스트

src/__tests__/live-data.test.ts 안의 기존 두 케이스에 expect.objectContaining({ windowsHide: true }) 추가:

  • replaces a basic !command with live-data output — executeCommand 커버
  • script block 케이스 — !begin-script 블록 러너 커버

소스에서 옵션을 다시 제거하면 이 두 케이스가 실패하는지 로컬에서 역검증 완료. npx vitest run src/__tests__/live-data.test.ts → 40/40, npx tsc --noEmit clean.
