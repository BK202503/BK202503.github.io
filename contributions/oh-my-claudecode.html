oh-my-claudecode — Windows execSync windowsHide

Yeachan-Heo/oh-my-claudecode (OMC, MIT). PR #3484 (fix(windows): avoid Git console flashes in hooks and HUD) 이 src/hooks/auto-slash-command/live-data.ts 안의 git-specific execFileSync 콜 두 개는 fix 했지만 같은 파일의 general command runner 두 개는 그대로 남아 있어서 !cmd live-data 치환과 !begin-script 블록 실행 시마다 Windows에서 cmd.exe console flash가 재발생. #3484 스윕에 맞춰 두 spot에 windowsHide: true 추가.

문제

#3484 이후 같은 파일의 두 execSync 콜에는 windowsHide 옵션이 안 붙어 있어 회귀 상태. executeCommand(command)는 매 !cmd 치환마다, !begin-script 블록 러너는 매 유저 스크립트 실행마다 각각 cmd.exe 창이 잠깐 뜸.

수정

두 execSync 옵션 객체에 windowsHide: true 만 추가. #3484 및 이전 스윕(#3454, #3455, #3498)들이 다 unconditional로 세팅한 패턴을 그대로 따름 — Node는 non-Windows 에서 이 옵션을 무시하므로 platform check 불필요.

회귀 테스트

src/__tests__/live-data.test.ts 안의 기존 두 케이스를 강화해 expect.objectContaining({ windowsHide: true }) 를 assertion 에 추가. 소스에서 옵션을 다시 제거하면 이 두 케이스가 실패하는지 로컬에서 역검증 완료. npx vitest run src/__tests__/live-data.test.ts → 40/40 통과, npx tsc --noEmit clean.
